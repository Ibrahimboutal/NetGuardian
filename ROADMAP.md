# NetGuardian Roadmap

## Phase 1 (Foundation)
- Backend and frontend automated tests
- CI and CodeQL workflows
- Env-based configuration and deployment consistency
- Auth/rate limits and incident retention controls

## Phase 2 (Operational Maturity)
- Incident lifecycle workflow and audit trail
- Alerting integrations
- Richer simulation and policy guardrails
- Observability dashboards and SLOs

## Phase 3 (Scale and Productization)
- RBAC and multi-tenant support
- Historical analytics and drift monitoring
- Advanced scenario/chaos simulation library
- Optional hybrid cloud relay mode
