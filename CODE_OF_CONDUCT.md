# Code of Conduct

## Our Pledge
We pledge to make participation in this project a harassment-free experience for everyone.

## Expected Behavior
- Be respectful and constructive.
- Assume positive intent and collaborate in good faith.
- Focus discussions on technical outcomes and community health.

## Unacceptable Behavior
- Harassment, discrimination, threats, or abuse.
- Publishing private information without consent.
- Repeated disruptive conduct.

## Enforcement
Project maintainers may remove, edit, or reject comments, commits, code, and other contributions that violate this Code of Conduct.
